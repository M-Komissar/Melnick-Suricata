
# Suricata Monitor

**Автоматизированный мониторинг и реагирование на сетевые угрозы.**

---

## 📖 Что это и зачем

Каждый день компьютеры отправляют в интернет тысячи DNS-запросов: «какой IP у google.com?», «какой у yandex.ru?». Обычно это безопасно. Но иногда среди запросов мелькают адреса, связанные с malware, фишингом или ботнетами. Проблема в том, что **вручную отследить такое невозможно** — трафик слишком плотный.

**Suricata Monitor** — учебный инструмент, который решает эту задачу **автоматически**:

1. **Слушает** сетевой трафик через **Suricata** (IDS с открытым исходным кодом).
2. **Собирает** DNS-события в лог `eve.json`.
3. **Проверяет** подозрительные **IP**, **домены** и **URL** через **VirusTotal API** (база 70+ антивирусов).
4. **Реагирует** на угрозы: звук, всплывающее окно, запись в БД, email, Telegram.
5. **Строит графики** и ведёт историю проверок — **отдельно для IP, доменов и URL**.

Инструмент работает в двух режимах:

| Режим | Что делает |
|---|---|
| 🟢 **Реальный** | Запускает Suricata, читает `eve.json`, ходит в VirusTotal API |
| 🟡 **Имитация** | Ничего не запускает и никуда не ходит — берёт готовые данные из `data/ip_list.json` или `data/ip_list_generated.json` |

**Режим имитации** нужен для:
- демонстрации без интернета;
- работы, когда Suricata не установлена;
- показа логики на заранее известных данных;
- **генерации случайных IP / доменов / URL** для теста (пункт 10 меню).

## ✨ Возможности

- 🕵️ **Пакетное сканирование** — сбор трафика за 15 секунд + анализ
- 🔍 **Проверка IP вручную** через VirusTotal
- 🌐 **Проверка доменов** через VirusTotal (из DNS-событий Suricata)

## 🚀 Установка — кратко

### 1. Python-библиотеки

```bash
pip install -r requirements.txt
```

### 2. Suricata

1. Скачай [suricata.io/download](https://suricata.io/download/) → **Windows 64-bit installer**.
2. Установи **от имени администратора**.
3. **Обязательно** отметь галочку **«Install Npcap»**.

### 3. Правила Suricata

Создай папки:

```powershell
New-Item -ItemType Directory -Force -Path "C:\SuricataTest\log"
New-Item -ItemType Directory -Force -Path "C:\SuricataTest\rules"
```

Создай файл `C:\SuricataTest\rules\local.rules`:

```
alert dns any any -> any 53 (msg:"DNS query"; sid:1000001; rev:1;)
alert dns any 53 -> any any (msg:"DNS response"; sid:1000002; rev:1;)
```

### 4. Настройка `suricata.yaml`

Открой `C:\Program Files\Suricata\suricata.yaml` **от имени администратора**.

Найди и измени:

**Директорию логов:**
```yaml
default-log-dir: C:\SuricataTest\log
```

**Блок eve-log** (в `outputs:`):
```yaml
  - eve-log:
      enabled: yes
      filetype: regular
      filename: eve.json
      types:
        - alert
        - dns:
            query: yes
            answer: yes
        - http
        - tls
        - flow
```

Сохрани.

### 5. Ключ VirusTotal

**Ключ больше не хранится в коде.** Он вводится:

* либо при **первом запуске** скрипта (мастер спросит);
* либо через меню **«Настройки уведомлений» → 11. Ввести API-ключ VirusTotal**.

Получить ключ:
1. Зарегистрируйся на [virustotal.com](https://www.virustotal.com/).
2. Профиль → **API key** → скопируй ключ.

Ключ сохранится в `data/config.json` (файл уже в `.gitignore`).

### 6. Интерфейс в скрипте

Открой `src/test.py`, найди:
```python
INTERFACE = "172.20.10.8"
```

Замени на **имя своего интерфейса** (`Wi-Fi`, `Ethernet`) или на **свой IP**.

Узнать имя:
```powershell
Get-NetAdapter | Select-Object Name, Status
```

Узнать IP:
```powershell
ipconfig
```

## 📦 Сборка в EXE (PyInstaller)

Позволяет получить **один файл `SuricataMonitor.exe`**, который запускается двойным кликом и **не требует установленного Python** у пользователя.

### 1. Установи PyInstaller

```powershell
pip install pyinstaller
```

### 2. Собери EXE

Из **корня проекта** (там, где `src/`, `data/`, `run.bat`):

```powershell
pyinstaller --onefile --console --uac-admin --name "SuricataMonitor" --icon "src\icon.ico" src\test.py
```

**Флаги:**

| Флаг | Значение |
|---|---|
| `--onefile` | Собрать всё в **один** `.exe` |
| `--console` | Оставить консольное окно (нужно для меню) |
| `--uac-admin` | При запуске **запросить права администратора** |
| `--name "SuricataMonitor"` | Имя итогового EXE |
| `--icon "src\icon.ico"` | Иконка приложения (опционально) |

### 3. Готовый файл

После сборки появится:

```
suricata-monitor/
├── dist/
│   └── SuricataMonitor.exe      ← готовый файл
├── build/                        ← временная папка (можно удалить)
└── SuricataMonitor.spec          ← временный файл (можно удалить)
```

**`dist\SuricataMonitor.exe`** — запускай двойным кликом.

### 4. Утилита автосборки `build.bat`

Создай в корне проекта файл **`build.bat`**:

```bat
@echo off
echo [*] Останавливаю старый процесс...
taskkill /F /IM SuricataMonitor.exe 2>nul

echo [*] Удаляю старые сборки...
rmdir /S /Q dist 2>nul
rmdir /S /Q build 2>nul
del /Q SuricataMonitor.spec 2>nul

echo [*] Собираю EXE...
pyinstaller --onefile --console --uac-admin --name "SuricataMonitor" --icon "src\icon.ico" src\test.py

echo.
echo [+] Готово: dist\SuricataMonitor.exe
pause
```

Двойной клик — и EXE пересоберётся с нуля.

## 🖼 Своя иконка и заголовок окна

### Иконка

1. Нужен **настоящий** файл `.ico` (не переименованный PNG).
2. Проверить формат:
   ```powershell
   Format-Hex -Path "src\icon.ico" -Count 16
   ```
   * `00 00 01 00` → ✅ настоящий ICO.
   * `89 50 4E 47` → ❌ это PNG, нужно конвертировать.
3. Конвертировать PNG → ICO: [icoconvert.com](https://icoconvert.com/) или [convertio.co](https://convertio.co/ru/png-ico/).
4. Размер — **256×256**.
5. Положить в `src/icon.ico`.

### Заголовок окна

Добавь **в самом начале `src/test.py`** (после `import`-ов):

```python
def set_window_title(title):
    try:
        ctypes.windll.kernel32.SetConsoleTitleW(title)
    except Exception:
        pass

set_window_title("Suricata Monitor — Автоматизированный мониторинг угроз")
```

После этого **обязательно** пересобери EXE.

## 👋 Первый запуск

Откроется **мастер настройки**:

1. **Режим VirusTotal** — реальный API или имитация.
2. **API-ключ VirusTotal** (если выбран реальный режим).
3. **Email** — выбери сервис (Яндекс / Gmail / Mail.ru) и введи пароль приложения.
4. **Telegram** (опционально) — токен бота и Chat ID.

Все данные сохранятся в `data/config.json` и будут использоваться дальше.

### Как получить пароль приложения

**Яндекс:**
1. [mail.yandex.ru](https://mail.yandex.ru) → Настройки → Все настройки.
2. «Почтовые программы» → включить IMAP и «Пароли приложений».
3. Создать пароль → тип «Почта» → скопировать 16 символов.

**Gmail:** [myaccount.google.com/apppasswords](https://myaccount.google.com/apppasswords).

**Mail.ru:** [mail.ru](https://mail.ru) → Настройки → Безопасность → пароль для внешних приложений.

## 📋 Меню

```
1.  Запустить новое сканирование (пакетный режим)
2.  Посмотреть историю сканирований
3.  Проверить IP, домен или URL вручную
4.  Фоновый мониторинг в реальном времени
5.  Справочник / Инфо
6.  Уведомления об угрозах (pending)
7.  Построить графики по истории
8.  Настройки уведомлений
9.  Режим VirusTotal (реальный/имитация)
10. Сгенерировать новые данные для имитации
11. Выход
```

| Пункт | Что делает |
|---|---|
| **1** | Пакетное сканирование: 15 сек трафика + проверка IP, доменов, URL |
| **2** | История: **отдельно** для IP, доменов и URL с группировкой и статистикой |
| **3** | Ручная проверка **IP, домена или URL** через VirusTotal |
| **4** | Фоновый мониторинг в отдельном окне |

## 🌐 Проверка доменов через VirusTotal

Помимо IP-адресов, скрипт **проверяет домены**, найденные в DNS-событиях Suricata.

### Как это работает

1. **Suricata** пишет DNS-события в `eve.json`, включая поля `dns.rrname` или `dns.queries[].rrname`.
2. **Скрипт** извлекает все домены из лога (`analyze_eve()`).
3. **Для каждого домена** отправляется запрос к VirusTotal API:
   ```
   GET https://www.virustotal.com/api/v3/domains/{domain}
   ```
4. **VirusTotal отвечает** — сколько антивирусов пометили домен как вредоносный.
5. **Результат** выводится в консоль, сохраняется в `report.json` и в БД (таблица `found_domains`).

### Пример вывода

```
----------------------------------------------------------------------
   ПРОВЕРКА ДОМЕНОВ ЧЕРЕЗ VIRUSTOTAL
----------------------------------------------------------------------
  [+] stats.g.doubleclick.net — ЧИСТЫЙ
  [+] ct.pinterest.com — ЧИСТЫЙ
  [+] api.oaistatsig.com — ЧИСТЫЙ
  [+] www.google.com — ЧИСТЫЙ (из белого списка)
----------------------------------------------------------------------
```

### Что попадает в БД

Таблица **`found_domains`**:
- `scan_id` — ID сканирования
- `domain` — домен
- `risk_level` — уровень риска
- `total_detections` — сколько обнаружений
- `malicious` — вредоносный или нет

### Ограничения

- **Проверяются только первые 5 доменов** — чтобы не упереться в лимит VirusTotal.
- **В режиме имитации** домены берутся из `ip_list_generated.json` (если есть) или `ip_list.json`.
- **Белый список** `TRUSTED_DOMAINS` — очевидно чистые домены не тратят запросы VT.
- **Кэш** `DOMAIN_CACHE` — повторно не проверяются.
- **Пауза 15 сек** между проверками — защита от `429 Too Many Requests`.

## 🔗 Проверка URL через VirusTotal

Скрипт **проверяет URL**, найденные в HTTP-событиях Suricata.

### Как это работает

1. **Suricata** пишет HTTP-события в `eve.json`, включая `http.hostname` и `http.url`.
2. **Скрипт** формирует полный URL: `http://{hostname}{url}` (`analyze_eve()`).
3. **Для каждого URL**:
   - **POST** `https://www.virustotal.com/api/v3/urls` с параметром `url={URL}`.
   - **Получает** `analysis_id` из ответа.
   - **Ждёт 5 секунд** — VT анализирует асинхронно.
   - **GET** `https://www.virustotal.com/api/v3/analyses/{analysis_id}` — получает результат.
4. **Результат** выводится в консоль, сохраняется в `report.json` и в БД (таблица `found_urls`).

### Пример вывода

```
----------------------------------------------------------------------
   ПРОВЕРКА URL ЧЕРЕЗ VIRUSTOTAL
----------------------------------------------------------------------
  [API] Проверка URL http://example.com/test через VirusTotal...
  [*] Analysis ID получен. Жду анализ (5 сек)...
  [+] http://example.com/test — ЧИСТЫЙ
----------------------------------------------------------------------
```

### Что попадает в БД

Таблица **`found_urls`**:
- `scan_id` — ID сканирования
- `url` — URL
- `risk_level` — уровень риска
- `total_detections` — сколько обнаружений
- `malicious` — вредоносный или нет

### Ограничения

- **Проверяются только первые 8 URL**.
- **Белый список** — URL из `TRUSTED_DOMAINS` не тратят запросы VT.
- **Кэш** `URL_CACHE` — повторно не проверяются.
- **Первый раз** — может вернуть **«В ОЧЕРЕДИ (VT анализирует)»**, потому что анализ асинхронный.
- **Со второго раза** — конкретный результат из VT или из кэша.

## 🔀 Режим имитации

Работает **без Suricata и без интернета** — читает данные из:
1. **`data/ip_list_generated.json`** — приоритет (авто-сгенерированные данные).
2. **`data/ip_list.json`** — если первого нет.

Формат файла:

```json
{
  "dns_events": [
    {"src_ip": "8.8.8.100", "rrname": "malware.example", "count": 5},
    {"src_ip": "1.1.1.50",  "rrname": "phishing.example", "count": 3},
    {"src_ip": "1.1.1.1",   "rrname": "cloudflare.com", "count": 12}
  ],
  "url_events": [
    {"src_ip": "8.8.8.100", "url": "http://malware.example/login", "count": 2},
    {"src_ip": "1.1.1.50",  "url": "http://phishing.example/account", "count": 1}
  ],
  "vt_responses": {
    "8.8.8.100": {"malicious": true,  "risk_level": "КРИТИЧЕСКИЙ",
                  "malicious_count": 10, "suspicious_count": 2},
    "1.1.1.50":  {"malicious": true,  "risk_level": "ВЫСОКИЙ",
                  "malicious_count": 3, "suspicious_count": 1},
    "malware.example":    {"malicious": true, "risk_level": "ВЫСОКИЙ",
                           "malicious_count": 5, "suspicious_count": 1},
    "http://malware.example/login": {"malicious": true, "risk_level": "КРИТИЧЕСКИЙ",
                                     "malicious_count": 8, "suspicious_count": 2}
  },
  "default_vt_response": {
    "malicious": false, "risk_level": "ЧИСТЫЙ",
    "malicious_count": 0, "suspicious_count": 0
  }
}
```

* **`dns_events`** — какие IP и домены «пришли из Suricata».
* **`url_events`** — какие URL «пришли из Suricata».
* **`vt_responses`** — что «отвечает VirusTotal» для IP, доменов и URL.
* **`default_vt_response`** — ответ для тех, кого нет в списке.

Файл читается **при каждом запросе** — можно править на лету.
